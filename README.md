

**AppleMapple** is a web-based, 3D arcade game built using HTML5, CSS3, JavaScript, and **Three.js** (WebGL). Designed with a clean, minimal, kid-friendly aesthetic, it features a playful white interface paired with vibrant gaming elements.

The core mechanics deliver an infinite, non-terminating gameplay loop where players control a red snake in a maroon-themed 3D playfield, collecting apples to grow and score points without punishing game-over screens.

---

## Technical Stack & Architecture

* **Frontend Framework & Rendering:** HTML5 / CSS3 / Vanilla JavaScript
* **3D Graphics Engine:** Three.js (WebGL rendering)
* **Typography:** `Fredoka` (Google Fonts – bubbly/kid-friendly weight)
* **Styling & Theme:** Minimalist, cardless layout; bright white primary palette with high-contrast maroon 3D game arena

---

## Key Features & Functional Modules

### 1. WebGL 3D Gameplay Loop

* **Non-Terminating Engine:** Features infinite wall-wrapping (teleportation across borders) and dynamic auto-respawn upon self-collision to maintain uninterrupted play.
* **Score & Growth System:** Real-time point tracking and dynamic snake segment expansion upon collecting apples.
* **Customization:** Color-picker interface allowing real-time modification of the snake's material color.
* **Persistent States:** Local storage integration for saving game states and high scores.

### 2. User Interface & Experience Design

* **Hero Section:** Features a prominent **PLAY** button in the center with playful, high-impact branding.
* **Navigation & Menus:** Clean menu controls for *New Game*, *Save Game*, *Scoreboard*, and *Snake Color*.
* **Zero Clutter:** Built without cards, progress bars, dot patterns, or italicized fonts to preserve a minimal, modern feel.
